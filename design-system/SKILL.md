Read the README.md file within this skill, and explore the other available files.
If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.
If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Key files:
- `README.md` — brand context, content & visual foundations, iconography
- `colors_and_type.css` — all design tokens (brand colors, blue ramp, accent tints, type scale, spacing, radii, shadows) + semantic type classes
- `assets/` — logos (blue, white, gold, magenta, teal @3x), the brand color sheet,
  slogan + slogan-lockup SVGs (full-color + mono blue/white)
- `preview/` — rendered foundation + component cards
- `ui_kits/marketing-site/` — interactive agency-website UI kit (React/JSX components + index.html)

Brand in one line: bold, optimistic blue (#3C4099) plus gold, magenta and teal, used as
full-bleed color fields with the wordmark recolored for contrast. No symbol mark — the
wordmark is the identity. Sora for headlines, Manrope for text.
